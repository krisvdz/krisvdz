# Simulado Técnico Frontend / React Native (Associate)

Este repositório foi criado no formato de teste técnico (estilo HackerRank/HackerEarth) para você praticar:

1. **Entrevista teórica guiada** (perguntas + respostas modelo + justificativa).
2. **Desafio prático** com bugs e tarefas por etapa.
3. **Gabarito completo** em pasta separada.

## Estrutura

- `interview-simulado.md` → simulado de entrevista técnica.
- `challenge-app/` → projeto com erros e pendências para você corrigir.
- `solutions/` → respostas do simulado + código corrigido.

## Como usar

1. Leia e responda em voz alta as perguntas em `interview-simulado.md`.
2. Vá para `challenge-app/README.md` e execute as etapas sem olhar as respostas.
3. Compare seu resultado com `solutions/`.

## Objetivo de nível

- Nível **Associate** (júnior/pleno inicial).
- Foco em fundamentos sólidos, qualidade e performance mobile.
- Sem system design complexo.
